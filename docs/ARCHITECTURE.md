# MoonlightOS Architecture (v2)

## Overview

MoonlightOS is an S-mode microkernel for RISC-V 64-bit. The kernel runs in
S-mode under OpenSBI (firmware owns M-mode + PMP). Userspace runs in U-mode.
All drivers, servers and the shell are userspace compartments. The proof
ground is the `V2` Isabelle/HOL session (`kernel/isabelle/`), built from an
abstract spec (V2_A) through an executable spec (V2_B, V2_C) down toward a
refined C implementation gated in CI (`tools/verify.sh`).

## Kernel

The kernel source lives in `kernel/` and builds with stock clang:

| File | LOC | Role |
|------|-----|------|
| `start.S` | ~30 | S-mode entry: gp init, BSS clear, `stvec`, call `kboot` |
| `trap.S` | ~140 | `s_trap_entry` (save all regs into `cur_ctx`), `u_enter` (noreturn switch to U-mode) |
| `kboot.c` | ~1920 | `kboot()` + trap dispatch + IPC + scheduling + capabilities + ELF/process ops + S3 NIC scan/demo/spawn |
| `user.c` | ~134 | U-mode ping-pong demo threads A and B |
| `elf.c` / `elf.h` | ~190 | initrd ELF validator + loader (window-base vpn, W^X, per-page file/BSS clamp) |
| `initrd.c` / `initrd.h` | ~60 | TOC-backed initrd blob accessor (`initrd_lookup`, fail-closed bounds) |
| `initrd_data.c` | generated | initrd blob + TOC, generated by `tools/mkinitrd.sh` (do not hand-edit) |
| `ipc.h` | ~180 | Endpoint queues (FIFO send/wait), user-range validation, host-testable |
| `qube.h` | ~190 | Qubes S1–S3 label + policy + raw-gate model (labels, `V2_RIGHT_QX`, QCREATE/QDESTROY ops, decide/ask/audit, `arg0`/`arg1` carry), host-testable |
| `caps.h` | ~400 | Stage-3 capability model (mint/grant/map/unmap/revoke, W^X, ELF validation), host-testable |
| `linker.ld` | ~25 | Kernel memory map |

### Boot and privilege model

1. **OpenSBI** sets up PMP, boots hart0 in S-mode, entry `_start` (`start.S`).
2. `_start` clears `_bss`→`_bss_end`, installs `stvec = s_trap_entry`, calls
   `kboot()`.
3. `kboot()` initialises Sv39 page tables with U-bit split:
   - `0x80200000`–`0x80400000` (kernel): text RX, data RW, no U.
   - `0x80400000`–`0x80600000` (user text): RX, U=1.
   - `0x80600000`–`0x80800000` (user data/stacks): RW, U=1.
   - UART MMIO at `0x10000000`: RW (mapped into kernel page table for
     SBI-forward via ecall to M-mode).
4. Switches on `satp = (8<<60)|PPN(root_pt)`, arms SBI timer, enables
   `STIE` + `SIE`, initialises two U-mode threads, enters thread A.
5. SPAWNs the initrd servers in order — mem_server (index 0, thread 2,
   qube 1), qrexec (index 1, thread 3, qube 2), adminvm (index 2,
   thread 4, qube 3), firewall (index 3, thread 5, qube 4), net
   (index 4, thread 6, qube 5) — printing `[spawn] <name> ELF ok` per
   server (`QUB: qube0 qube1 up` base-qube marker once labels land;
   brokers/qubes 2-5 covered by the `[spawn]` lines plus `NETQ: labels
   ok`), then runs the S2 demo (`QUB: xread denied`, `QREXEC: ask` /
   `QREXEC: allow` / `QREXEC: deny`, `AUD: 3 entries`), the S3 Phase-1
   model demo (`FW: allow` / `FW: deny`, `LEAK: denied`,
   `SPOOF: ignored`, `AUD:`), and the MMIO-leaf gate print
   (`NETMMIO: tid=6 only`) before entering thread 0. The firewall/net
   ELFs print `FW: up` / `NET: up` from U-mode, and the net ELF runs
   the deterministic link/tx/irq self-test (`NET: link up`,
   `NET: tx ok`; the kernel prints `NET: irq ok` on the PLIC→notify
   path).

### Scheduling

Lowest-numbered-Runnable (mirrors the proven `V2_A.sched_step`). Timer
preemption is the SBI timer interrupt (`scause=5`, 100ms @ 10MHz). Terminal
state is `wfi` when no thread is Runnable (prints `no runnable left; parking cpu`).

### IPC (Stage 2)

Blocking rendezvous on a static endpoint `EP0` with FIFO send/recv queues
(mirrors `V2_C`):

- `V2_SEND(ep, u_ptr, len)`: validate endpoint + range → SUM-window
  `u_copy_in` → deliver to oldest waiter (resume sender, stamp sender id,
  flag truncation) or queue + block.
- `V2_RECV(ep, u_buf, cap)`: validate → deliver oldest queued sender or
  park `(ptr, cap)` + block.
- `V2_NOTIFY(target, bits)`: OR-accumulate into `notify`; wake only a
  `WAIT`-blocked thread (rendezvous blocks untouched).
- `V2_WAIT()`: take pending notify bits, or block until notified.

Sender ids are **kernel-stamped** (never user-supplied). Truncation returns
an explicit overflow flag (`ovf`), never silent cut. The copy discipline is
validate-then-copy through a bounded loop with `SUM` toggled only for that
loop.

### Qubes labels + raw gate (S1, built)

Every thread carries a qube label (`qube_of[]` in `kboot.c`, 8 threads:
0–1 demo, 2 mem_server qube 1, 3 qrexec qube 2, 4 AdminVM qube 3,
5 firewall qube 4, 6 net qube 5, 7 CAP scratch).
Cross-qube SEND/RECV fails closed with `V2_ERR_INVALID` plus
`QUB: xread denied` unless the sender holds `V2_RIGHT_QX` (see
`qube_raw_ok` in `kernel/qube.h`, host-tested by `tests/test_qlabels.c`).
Both delivery sites stamp the RECV registers
`(a0=nw, a1=sender_tid, a2=sender_qube, a3=ovf)`.

`V2_INV_QCREATE` (14) loads an initrd ELF into a fresh thread under a new
label (`QUB: qube<N> up`); `V2_INV_QDESTROY` (15) parks every member
thread, drains their in-flight IPC, revokes their caps and clears their
mappings (`QUB: qube<N> dead`). Reserved args must be zero. Refined by
`c_q_call_refines` / `c_q_destroy_refines` in `Qubes_B.thy`.

### Packet plane (S3, built)

AppVM → firewall → net by R-only cap grants, never by copy; control
moves as `T_CALL(net.send, slot, len)` / `T_DECIDE` / `T_DELIVER` /
`T_FWD[6, slot, len, h]` / `T_DONE[7, slot, 0, 0]`. The firewall
(`userspace/firewall/v2_main.c` → `userspace/build/firewall.elf`) runs a
single-flight pipeline: one RECV per loop iteration, MAP slot 8 at
scratch vpn 8, `fw_decide` (`userspace/firewall/fw.h`: first-match-wins,
default-deny, IPv4/TCP-UDP/ports, `len ≤ 1514`) over the bytes — ALLOW
grants R onward + `SEND T_FWD`, ASK and DENY unmap + reply INVALID +
`FW: deny` (no prompter path, so Ask resolves as deny). The net stub
(`userspace/net/v2_main.c` → `userspace/build/net.elf`) honors only
`T_FWD` stamped `sender_qube == FW_QUBE` (4) with `slot == NET_IN_SLOT`
(8): it MAPs, recomputes `qube_fnv1a` (C FNV-1a; Qubes_C models it as the pkt_hash byte-sum stand-in) over `len` bytes, and compares to
the announced hash — mismatch is a silent drop (spoof-class, no oracle),
match prints `NET: fwd ok`, UNMAPs, and `SEND`s `T_DONE` back. Ask
payloads survive suspend/resume via `v2_qask_t` `arg0`/`arg1`
(frame+len); arg-less RPCs forward zeros. Proved by `packet_integrity`,
`deliver_allow_pins`, `net_trust_deliver`, `fw_default_deny_nomatch`,
`c_decide_args_eq` in `Qubes_C.thy`.

### NIC MMIO/IRQ (S3 Phase 2, built)

Eight virtio-mmio transports at `0x10001000+i*0x1000`, IRQ `1+i`; the NIC
is never assumed at transport 0. At boot `kboot.c` scans all 8 for
magic + version 2 + net device id 1 and records `net_virtio_irq = 1+ti`
(fail-closed `0xFFFFFFFF` when absent); the net ELF repeats the scan
from U-mode (`net_find`, `j < 8`). The transport pages reach U-mode
through exactly one leaf: `l0_netmmio` (all 8 pages, RW, never X) wired
at `l1_t[6][5]` — `NET_UVA 0x80A00000` — so net MMIO reach is 8 pages,
tid-6-only, asserted at boot (`NETMMIO: tid=6 only`). The `scause=9`
handler claims both PLIC contexts, and when the source is the recorded
NIC IRQ it raises `NOTIFY` badge `NET_IRQ_BIT` on tid 6, waking only
genuine WAIT waiters (`NET: irq ok`); anything else logs
`IRQ: unexpected` and wakes nobody. The link/tx/irq self-test is
deterministic: link-status bit → `NET: link up`, one 60B gratuitous ARP
with used-ring completion + IRQ wait → `NET: tx ok`; no external fetch
is asserted and RX-from-wire stays manual-only. QEMU runs the single
cmdline with `-device virtio-net-device,netdev=n0 -netdev user,id=n0`
plus `-global virtio-mmio.force-legacy=off` (modern transports; the
`-global` also flips blk to modern mode, which the block driver already
probes via `vmm_probe`).

### Memory isolation

Kernel text is `RX` (no W, no U); kernel data is `RW` (no U). User text is
`RX` (no W, no kernel); user data/stacks are `RW` (no kernel). SUM is 0
except during the bounded `u_copy_in`/`u_copy_out` window. Each thread has
its own VSpace (`root_pt_t`/`l1_t`/`l0_u_t` per thread, `satp` switched in
`enter_thread`); the frame window (`0x80800000` + vpn*4096) is per-thread,
backed by real frames at `0x81000000` + frame*4096. No PMP changes (yet):
firmware owns PMP.

### Fault containment

Illegal instructions, page faults, and unknown interrupts park the offending
thread and keep the rest running (`[fault] tcb=N cause=... parked; others
continue`).

## Capability model (Stage 3, built)

The host-tested model lives in `kernel/caps.h` (tests/test_v2caps.c). Frame
pool (`V2_FRAMES_MAX=16`), per-thread cap slots (`V2_CAP_SLOTS=32`), and a
linear mapping table (`V2_VPN_SLOTS=32`). Operations: `v2_mint` (attenuate
own cap, root bit cleared on copy), `v2_grant` (cross-thread copy), `v2_map`
(cap right + VPN → mapping; W+X together rejected, W^X enforced), `v2_unmap`,
`v2_revoke`
(destroy all non-root caps to an object system-wide + drop all its mappings).
Root caps survive revocation (the allocator/mem_server retains them).
`Invoke` ops `V2_INV_MINT/GRANT/MAP/UNMAP/REVOKE/PT_ALLOC/WRITE/READ` drive
real Sv39 leaf PTEs + `sfence.vma` (fail closed: no PTE change on model
rejection); `V2_INV_ELF_MAP/SPAWN/FORK/EXEC` are the process ops
(`FORK` is COW with the model as authority — see `kboot.c`).

ELF validation (`v2_elf_ok`): magic check, 1–4 segments, 1–512 pages each,
never W+X. Data read/write: needs both a valid cap right AND mapping right
(mirrors the spec `d_write`/`d_read`).

## Userspace (frozen v1 features)

The v1 M-mode kernel was removed; the v1 userspace feature set survived via
the frozen ABI headers in `userspace/abi/` (types, cap, cheri, iommu, vspace,
linux_abi — self-contained, host-compilable). These provide the syscall
numbers and structure definitions against which the drivers and servers
compile. The freestanding C library lives in `userspace/libc/`. Driver and
server code uses only `userspace/abi/` headers — never `kernel/` headers.

Build gate: `make -C userspace` (freestanding rv64 ELFs) +
`make -C userspace drivers` (freestanding rv64, `-Werror`, driver objects
validates the ABI headers).

## Verification

`tools/verify.sh` is the single source of truth:

1. **Host unit tests**: ABI regression (uintptr_t = 8), sched_server, vfs,
   shell, driver host-sims (uart/plic/timer/rtc/power), freestanding libc
   (test_libc + newlibc + batch4/5/6), v2 IPC + caps (host-compiled from
   `ipc.h`/`caps.h`), qube labels + policy (`test_qlabels`,
   `test_qube_policy` from `qube.h`), ask args (`test_qargs`), firewall +
   net plane (`test_netfw` over `fw.h`).
2. **Production gates**: linker layout (no PROGBITS in `[_bss,_bss_end)`),
   `user.c` rodata ban (immediates-only U-mode code).
3. **Isabelle**: `isabelle build -D kernel/isabelle -v` (session V2 =
   V2_A + V2_B + V2_C + V2_D + Qubes_A + Qubes_B + Qubes_C; anti-vacuity gate: no sorry,
   no `≡ True` invariants).
4. **Kernel build**: `make -C kernel` (clang, rv64imac, freestanding).
5. **QEMU smoke** (single cmdline: virtio-net-device + user netdev +
   `virtio-mmio.force-legacy=off`): boots OpenSBI → kernel, asserts `satp Sv39 on`,
   `entering U-mode`, `B00pn`, `A10pg`, `W1`, `[spawn] mem_server ELF ok`,
   `MEM-SRV`, `MEM`/`CAP`/`OK` invoke reports, `DU: vpn0 mirrored`,
   `NP`, `[spawn] qrexec/adminvm ELF ok`, `QUB: qube0 qube1 up`
   (base-qube marker; brokers/qubes 2-3 covered by the `[spawn]` lines),
   `QUB: xread denied`, `QREXEC: ask` / `QREXEC: allow` / `QREXEC: deny`, `AUD: 3 entries`,
   `[spawn] firewall/net ELF ok`, `NETQ: labels ok`, `FW: allow` /
   `FW: deny`, `FW: up`, `NET: up`, `LEAK: denied`, `SPOOF: ignored`,
   `AUD:`, `NETMMIO: tid=6 only`, `NET: link up`, `NET: tx ok`,
   `NET: irq ok`, `no runnable left; parking cpu`. Missing markers fail the gate
   (fail closed).

CI (`verify.yml`, `cheri.yml`): the host-tests job runs `verify.sh`; the
isabelle job runs the proofs in the Isabelle container; the CHERI job
confirms the kernel also compiles under `riscv64-unknown-elf-clang` (CHERI
toolchain gate — the kernel remains `-march=rv64imac` today).
