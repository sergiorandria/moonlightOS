# x86_64 Port (Q35 + OVMF) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Boot the v2 microkernel on QEMU x86_64 Q35 + OVMF with full parity to RISC-V (10 threads, same UABI, same 44-marker smoke).

**Architecture:** Split `kernel/kboot.c` into shared `kernel/core/` + `kernel/arch/riscv/` (moved) + `kernel/arch/x86_64/` (new UEFI/PML4/IDT/PCI backend) behind `kernel/arch/hal.h`; recompile all ten userspace ELFs for x86_64 with `syscall`-based stubs.

**Tech Stack:** clang + lld freestanding (`--target=x86_64-unknown-elf -mno-red-zone -mcmodel=kernel`), OVMF (UEFI `ExitBootServices`), qemu-system-x86_64 `-M q35`, x86_64 PML4 / IDT / GDT / TSS / LAPIC / IOAPIC / PCI virtio-pci, FAT ESP image (`mtools`/`mkfs.vfat`).

**Spec:** `docs/superpowers/specs/2026-09-25-x86-64-port-design.md`

## Global Constraints

- UABI numbers/semantics identical: `V2_YIELD 0, V2_PUTC 1, V2_PARK 2, V2_SEND 3, V2_RECV 4, V2_NOTIFY 5, V2_WAIT 6, V2_INVOKE 7`; invoke ops `V2_INV_MAP 3, UNMAP 4, REVOKE 5, PT_ALLOC 6, ELF_CHECK 7, ELF_MAP 8, SPAWN 9, FORK 10, EXEC 11, WRITE 12, READ 13, QCREATE 14, QDESTROY 15`; reserved invoke args must be zero (fail closed).
- U window stays `0x80800000`, 32 slots, `vpn = (p_vaddr - BASE) >> 12`; `NTHREADS 10 <= V2_CAP_THREADS`; per-thread endpoints `V2_NEP 10` with own-EP rule (`ep != cur → V2_ERR_INVALID` before any queue touch).
- x86_64 syscall wire: `syscall`, `rax=sys`, `rdi=ep/cap`, `rsi=buf`, `rdx=len`, `r10=aux`; returns `rax=nw`, `rsi=sender`, `rdx=qube`, `r10=ovf`; `rcx/r11` clobbered, never data.
- W^X everywhere, no `W+X` segment; `core/` never references `satp/stvec/scause/sepc/ecall/sum/cr3/idt/iret/stac` directly (HAL-only, grep-gated).
- Every missing smoke marker is FAIL, never SKIP; no stub prints a server marker.
- Default `make -C kernel` output (`kernel/build/moonlight.elf`) stays byte-identical to today after the move-only refactor.

`kernel/arch/x86_64/console.c` (exact, COM1 0x3F8):
```c
static void outb(unsigned short p, unsigned char v) {
    __asm__ volatile("outb %0,%1" : : "a"(v), "Nd"(p));
}
static unsigned char inb(unsigned short p) {
    unsigned char v;
    __asm__ volatile("inb %1,%0" : "=a"(v) : "Nd"(p));
    return v;
}
void hal_putc(char c) {
    while (!(inb((unsigned short)0x3FD) & 0x20)) {}
    outb((unsigned short)0x3F8, (unsigned char)c);
}
void hal_park(void) {
    for (;;) __asm__ volatile("hlt");
}
```
