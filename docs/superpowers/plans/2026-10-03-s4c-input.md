# S4c Input Takeover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take over the in-tree S4c VirtIO input + console WIP and land it green with kernel edits, proofs, and gates.

**Architecture:** Audit-fix the userspace WIP first (S4b frozen as reference), then apply the kernel side in two commits (leaves/wiring, then IRQ/discovery), then gates/proofs/live-input acceptance, then retro-spec and landing cleanup.

**Tech Stack:** Freestanding C99 rv64 (`clang --target=riscv64-unknown-elf -march=rv64imac -mabi=lp64 -ffreestanding -nostdlib -Werror`), host gcc KATs, Isabelle V2_C, QEMU virt `virtio-keyboard-device`/`virtio-mouse-device`.

**Spec:** `docs/superpowers/specs/2026-10-03-s4c-input-design.md` (forward design) + in-tree `KERNEL_INPUT_CHANGES.md` (the WIP's 8-change kernel guide — follow its insertion points, adapt per Task 2 notes).

## Global Constraints

- No `NTHREADS` / `V2_NEP` / `V2_CAP_THREADS` / `V2_FRAMES_MAX` / `V2_MSG_MAX` / `V2_VPN_SLOTS` change (11/11/11/40/4/32 hold).
- gui.elf total mapped pages ≤ 8 (slots 0..7; slot 9 stays free for the S4b QX grant — S4b R2 lesson).
- S4b markers (`GUI: up`, `GUI: fill ok`, `GUI: composed ok`) keep printing at every task; `R_OK 0` / `R_DENY -1` single reply; chrome 20px server-only.
- `-Werror` everywhere; every loop carries `/* bound: */`; U=0 in `kernel/user.c` (no string literals/globals).
- `V2_D` untouched; `max_eps=11` untouched.

```c
/* tests/test_input.c - KATs for gui/input.h (key/mouse) + gui/console.h (grid). */
#include <stdio.h>
#include <string.h>
#include "../userspace/gui/input.h"
#include "../userspace/gui/console.h"
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); return 1; } while (0) }
int main(void) {
    kbd_modifiers_t m = {0, 0, 0};
    CHECK(keycode_to_ascii(KEY_1, &m) == '1');
    CHECK(keycode_to_ascii(KEY_ESC, &m) == 0x1B);
    update_modifiers(&m, KEY_LEFTSHIFT, 1);
    CHECK(m.shift == 1);
    CHECK(keycode_to_ascii(KEY_A, &m) == 'A');
    update_modifiers(&m, KEY_LEFTSHIFT, 0);
    m.ctrl = 1;
    CHECK(keycode_to_ascii(KEY_A, &m) == 0x01);
    m.ctrl = 0;
    CHECK(keycode_to_ascii(200, &m) == 0);
    mouse_state_t ms = {0, 0, 0, 0, 0};
    mouse_move(&ms, -50, -50);
    CHECK(ms.x == 0 && ms.y == 0);
    mouse_move(&ms, 5000, 5000);
    CHECK(ms.x == 799 && ms.y == 599);
    mouse_button(&ms, BTN_LEFT, 1);
    CHECK(ms.left == 1);
    console_t con;
    console_init(&con);
    CHECK(con.cursor_x == 0 && con.cursor_y == 0);
    for (int i = 0; i < 40; i++) { /* bound: 40 > 37 rows, forces scroll */
        char w[8]; w[0] = 'x'; w[1] = '\n'; w[2] = 0;
        console_puts(&con, w);
    }
    CHECK(con.cursor_y == 36);
    printf("PASS: test_input\n");
    return 0;
}
```
